# 🛍️ Catálogo Web Comercial y Detalle Interactivo



Aplicación web responsiva desarrollada con JavaScript Vanilla enfocada en la renderización dinámica de productos, navegación fluida a vistas de detalle y gestión interactiva de formularios.



## 🚀 Características Principales

- **Mock Data & Carga Dinámica:** Consumo y desacoplamiento de datos de catálogo a través de estructuras JavaScript/JSON locales (`data.js`).

- **Renderizado Dinámico en el Cliente:** Manipulación del DOM en tiempo real para generar listados de productos y vistas individuales.

- **Navegación Interactiva:** Transición fluida entre el catálogo general y la vista de detalle de cada producto.

- **Validaciones en el Frontend:** Control de estados y validación de campos en formularios de contacto.

- **Diseño Responsivo:** Adaptabilidad visual para dispositivos móviles y de escritorio mediante CSS Grid y Flexbox.



## 🛠️ Stack Tecnológico

- **Lenguaje:** JavaScript (ES6+, DOM API)

- **Estructura y Estilos:** HTML5 Semántico, CSS3 (Flexbox, Grid)

- **Data Source:** JSON / Objetos JS (Client-side Data)
